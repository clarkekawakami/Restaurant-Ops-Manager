# Restaurant Operations Manager

A simplified system managing restaurant menus, orders, and users. Built by Google AI Studio

## Features
- **Full-stack restaurant management web application**.
- **Restaurant POS, seating management, reservations**.
- **Menu Management with Gross Margin insights**.
- **Simplified Inventory Control for high value inventory items**.
- **Staff timekeeping and tip management support**.
- **Local Database Support**: SQLite.
